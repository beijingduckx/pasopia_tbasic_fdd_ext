# PASOPIA (PA7010) T-BASIC FDD拡張

T-BASIC (ROM BASIC) にフロッピーディスクのアクセス機能を拡張するパッチキットです。

T-BASIC の ROMイメージから、機能拡張版 T-BASIC が起動可能なディスクイメージを生成します。


ドライブの割り当ては、以下の通りです。

- `"1:"` 〜 `"4:"` = フロッピーディスク (物理ドライブ 1〜4)
- `"5:"` = RAM パック (従来どおり併用可能)

フリーエリアは files=6 (デフォルト) で約 26,200 バイトです

ファイルシステムは、パソピア7互換です。T-DISKBASICともやり取りができると思われますが、確認できていません。

## 使い方 (ディスクイメージの作成)

### 必要なもの
- 本リポジトリのリリースzip内のファイル一式
- 純正 T-BASIC version1.1 の ROM イメージ\
  ファイル名を`tbasic.rom` (32,768 バイト) としてください。

### 生成方法
1. リリースzip内のファイルを解凍したフォルダに、`tbasic.rom`を置きます。
2. PowerShell を起動し、上記のフォルダに移動します
3. 以下のコマンドを実行します
```powershell
.\build_boot_disk.ps1 -RomPath C:\path\to\tbasic.rom
```

これで、`pasopia_boot.2d` が生成されます。\
内容はブート可能なベタ2Dイメージで、先頭トラック含めすべて256bytes/sectorです。

BASICが格納されているエリアのFATは確保済みと設定してあるため、このディスクの空きエリアに
プログラムをセーブすることが可能です。

### 起動方法
生成されたディスクイメージをエミュレータでブートすることで、BASICが起動します。

実機の場合は、何等かの方法でディスクイメージを実ディスクに書き戻すなどし、書き込んだディスクをブートします。

PASOPIA7のように、起動時にドライブ数を確認することはありません。
通常の T-BASIC と同一の `How many files(0-15)?`の表示で起動します。


## リリースファイル一覧

| ファイル | 内容 |
|---|---|
| `build_boot_disk.ps1` | `tbasic.rom` から .2d を生成するスクリプト (要 PowerShell 5.1 以降) |
| `disk_basic.sym` | pasmo 形式が生成したシンボルテーブル | 
| `disk_basic.bin` | FDD拡張部バイナリ (0x8000~のコード)|
| `bootsec.bin` | ブートコード (ROMからロードされ、BASIC本体をロードします)|


## ソースコードからのビルド

> [!NOTE] 
> ディスクイメージの構築だけなら、ソースコードからのビルドは、必要ありません。

### 必要なツールチェイン
[pasmo](https://pasmo.speccy.org/) (開発時は、Version 0.5.3を利用)

### 構築方法

以下のコマンドを実行します。
```sh
pasmo disk_basic.asm disk_basic.bin disk_basic.sym
pasmo bootsec.asm bootsec.bin bootsec.sym
```

(disk_basic.binの上限サイズは 1,136 バイト = 8000h–846Fh です)

### ROM パッチ一覧

| パッチアドレス | 内容 |
|---|-----|
| 17B2h | レコード転送の最下層のフック |
| 45C8h | ディレクトリ読み |
| 45E1h | ディレクトリ書き戻し |
| 45B2h | FAT コピー読み |
| 4538h | FAT 書き戻し |
| 47D1h | レコード転送の入口 (管理領域のみフック) |
| 0807h | タイマ割り込み (64Hz) フック |
| 02CAh | コールドスタート入口 (02C9h) の CALL 161Bh の飛び先を変更し、元の処理の後にドライバのワーク初期化を行う |
| 7E6Eh | デバイス数のデフォルトを 6 に |
| 7E94h | テーブル種アドレスを 8470h へ (ドライバ直後にテーブルを配置) |
| 41B2h | FILES のデバイス番号を 1 始まりに (FILES 1 = FDD、FILES 5 = RAM パック) |
| 38B2h | ファイル名文字列のデバイス接頭辞 `"n:"` を 1 始まりに (`"1:"` = FDD、`"5:"` = RAM パック) |
| 408Eh | ファイル属性文の数値デバイス番号を 1 始まりに |
| 447Fh | OPEN 系のデバイス番号を 1 始まりに |
| 48B1h | デバイス番号を取る関数 (DSKF とみられる) の番号を 1 始まりに |
| 165Dh | 記述子検証 (1635h): FCAA=1 (サイドがある記録媒体) の記述子を受け付けるように。DSKO$/DSKI$ は(ドライブ, ヘッド, トラック, セクタ) 形式になる |
| 1636h | RAMPACプローブへのパッチ(1635h): 純正はコア0の選択時にRAMPACの存在をプローブするが、これをコア4の選択時に変更 |
| 7FC0h | 起動時サインオンの拡張: バージョン文字列 (7F90h) の終端以降の未使用 00h 領域 (7FC0h-7FF7h) に3行目を追加する |



## 動作確認環境

- PA7010 + PA7200 (2ドライブ) + [偽PAC2 for PASOPIA/7](https://github.com/shippoiincho/nisepac2)

## 制限
- T-BASIC Version 1.0 は対応していません
- 両面倍密度(2D)ドライブ・メディアのみ対応です
- T-DISKBASICで拡張された機能・命令はサポートしていません\
その命令を含んだBASICコードをロードした場合の動作は、保証できません

## Known Issues
- 実機では、BASIC起動直後の最初のディスクアクセスが CRC エラーになります。\
 リトライにより隠ぺいしていますが、現在原因不明です
- 存在しないドライブや、ディスクが刺さっていないドライブにアクセスすると、エラーとなるまで相当(40秒程度)時間がかかります\
これは、前述のリトライによるものです
